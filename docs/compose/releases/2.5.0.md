✨ 2.5.0 更新（BUILD 20048）

这是 2-Pyramid 的正式版（tag: Stable-2.5.0）。本版主线：**Foray 分析工作台**、**MSI 安装包**、通知与安装器静默部署。

可通过应用内「更新通道」检查到，或直接下载：

- `2-Pyramid-Installer.msi`（推荐，固定名，便于脚本 / 部署）
- `2-Pyramid-Installer-2.5.0.exe`（自研安装器）

✨ 新增

Foray（Editor Mode）：设置中开启 EM 后，主页拖入 zip 进入分析工作台——ROM 树、五类探针（文件 / 权限 / 加密 / 解析 / 恶意）、轻量像素编辑（涂抹 / 吸管 / HSV）、可选 AI 分析（OpenAI 兼容，档位 0–5，贴图只发概括与直方图）。默认关闭，不影响普通转换。

MSI：`2-Pyramid-Installer.msi`（WiX x64）。静默安装：`msiexec /i 2-Pyramid-Installer.msi /qn`。不做 MSIX。

安装器静默：`2-Pyramid-Installer-2.5.0.exe --silent [--dir <path>] [--relaunch] [--shortcuts]`。

系统通知改走 Rust 插件路径（notify-rust），桌面 Toast 为主通道。

🔧 改进 / 修复

- Foray：问题 / 轻量编辑 / AI 报告独立弹窗；图片灯箱可缩放；返回键可用。
- 通知：Toast 窗口权限与透明修复；系统通知失败自动回退桌面 Toast。
- Foray 导出：未修改文件字节保留；原地覆盖写 .bak 并可回滚。

🔐 法律

`legal/`（中英）：Foray 外部 AI API 免责与隐私、MSI 静默部署说明。
