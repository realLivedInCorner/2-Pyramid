✨ 2.1.1 正式版更新（BUILD 20037）

这是 2-Pyramid 的正式版（tag: Stable-2.1.1）。包含此前 2.1.0 / Beta 的全部内容（界面动画、Java ↔ 基岩双向转换基础链路等），另加下列修复与增强。

可通过应用内「更新通道 → 稳定版 / 全部」检查到，或直接在 Releases 下载 2-Pyramid-Installer-2.1.1.exe。

✨ 新增 / 增强

Java → Bedrock 界面补全：快捷栏、血量、饥饿、护甲等 HUD 与容器界面（箱子 / 工作台 / 熔炉族 / 酿造 / 附魔 / 砂轮 / 铁砧等）按可用包路径处理；无源 icons.png 时从 1.20+ sprites 拼图集。

Java 版本间着色器适配（1.20 → 26.x）：关键版本边不再整目录删除 shaders，改为补全与改写（include 命名空间、globals.glsl、fog_distance 提示等）。

🔧 修复 / 改进

基岩中间态统一到最新 Java 26.2（pack_format 88）。

床手持、桶 / 弓弩、原木木板、盔甲层等可见贴图路径对齐 vanilla；1.20+ sprites / heart / container 正确并入 ui/。

停止写入自生成 item_texture / terrain_texture（会破坏物品栏图标）；药水铺开到全部 potion_bottle_* 变体。

覆盖包 small_item 路径修正（缩小物品此前不生效）。

转换页与返回按钮视觉统一。
