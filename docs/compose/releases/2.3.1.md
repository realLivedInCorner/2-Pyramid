✨ 2.3.1 正式版更新（BUILD 20044）

这是 2-Pyramid 的正式版（tag: Stable-2.3.1）。针对 2.3.0 的界面回归做修复：覆盖包编辑子页排版、法律信息关闭方式，以及安装器在已安装时的进入路径。

可通过应用内「更新通道 → 稳定版 / 全部」检查到，或直接在 Releases 下载 2-Pyramid-Installer-2.3.1.exe。

🔧 改进

物品语言编辑：改为近全宽面板 + 双列平铺卡片（短 ID、输入框、预览紧凑排在一行），不再是一条占满整行的竖排列表。

🐛 修复

覆盖包三个编辑子页（自定义名称 / 物品大小 / 视觉）：类名与全局居中弹窗皮肤隔离，恢复正确宽面板 / 侧栏布局；点击遮罩可关闭。

弹层退出：黑幕先淡出再滑走面板，不再残留暗底。

法律信息侧栏：补齐遮罩样式，点击侧栏外空白即可退出（此前遮罩无定位与背景，点空白无效）。

安装器：本机已安装时直接进入覆盖更新流，双击新安装包也会走 3 步更新，而不是完整全新安装向导。

发版说明：本 Release 需同时上传 2-Pyramid-Installer-2.3.1.exe 与
2-Pyramid-Installer-2.3.1.exe.sha256 两个资产（更新器 SHA-256 校验依赖后者）。

校验（本次构建）：
- 2-Pyramid-Installer-2.3.1.exe.sha256: d76b0c51ce8bcf98885952ac3b51f239aa2b9c3e2490f271dddcd7450b10fe06
