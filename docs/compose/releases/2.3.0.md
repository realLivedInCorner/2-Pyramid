✨ 2.3.0 正式版更新（BUILD 20043）

这是 2-Pyramid 的正式版（tag: Stable-2.3.0）。本版本完善应用内更新体验（覆盖更新向导 + 按 major.minor.patch 判定是否强制），并继续拆分前端大文件、修复依赖安全告警。

可通过应用内「更新通道 → 稳定版 / 全部」检查到，或直接在 Releases 下载 2-Pyramid-Installer-2.3.0.exe。

✨ 新增

应用内覆盖更新向导：从 2-Pyramid 检查更新并安装时，安装器识别为「覆盖更新」，不再走完整全新安装流程。三步：确认版本对比 → 覆盖写入进度 → 完成（可一键启动）。锁定原安装目录；用户数据（~/.2pyr）与现有快捷方式保持不变。若旧版主程序仍在运行，会提示退出后再更新。

更新级别（major.minor.patch）：按语义化版本比较，major / minor / patch 任一升高才提示更新。major 升位与 Safe-* tag 强制更新（启动直接弹窗，不可跳过）；minor / patch 为可选更新，用户自愿，启动仅轻提示。更新弹窗显示「重大 / 功能 / 修复」徽章与说明。

设置页摘要：「版本详情」右侧直接显示 v{版本}+{构建号}；「作者与贡献」右侧显示主开发者与人数。

🔧 改进

前端继续模块化：设置、转换、覆盖包弹窗与版本侧栏拆为独立组件；Minecraft 版本目录独立维护。

覆盖包：打开项目后「返回」先回项目列表，再回首页。

主页底部 Dock / OOBE 底部导航：保留上浮反馈，曲线更稳，去掉缩放弹跳。

开发者选项：动作监视状态条（录制指示、帧数、本地实时流端口）。

🔒 安全

vue-i18n → 10.0.8（CVE-2025-53892）

vite → 6.4.3（多条 dev-server 路径穿越 / fs.deny 绕过，仅影响本地开发）

rustls → 0.23.45（RUSTSEC-2026-0285，TLS 1.3 握手层边界）

🐛 修复

移除误生成的 vite.config.js（会盖住 vite.config.ts）。

动作监视导出与实时协议补全（多事件类型、真实视口、CLICK / SHOT / STATUS 等，供内部工具 Action Mon3tr 使用）。
