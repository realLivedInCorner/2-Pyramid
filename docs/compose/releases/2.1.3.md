✨ 2.1.3 正式版更新（BUILD 20039）

这是 2-Pyramid 的正式版（tag: Stable-2.1.3）。在 2.1.2 基础上修复图层修复未生效、创造栏 tabs 对齐，并把着色器适配做成实验开关。

可通过应用内「更新通道 → 稳定版 / 全部」检查到，或直接在 Releases 下载 2-Pyramid-Installer-2.1.3.exe。

✨ 新增

着色器适配（实验）：转换页可开关。默认开启，按目标版本改写 fog / #moj_import / globals.glsl 等；关闭则原样保留 shaders，方便对比试转。

npm test：一键运行 Rust 单元测试（当前 133 项）。

🔧 改进

应用内更新仍走安装向导：下载后点「开始安装」打开安装界面，由你确认后完成更新。

内部 converters 按 ui / textures / reverse / color / audio / shaders 分模块，便于后续维护。

hurray 调度与贴图缓存轻量优化（少拷贝）。

创造栏 tabs 切片与 Python 版 pack.py 对齐，避免 1.8 图集误裁出「假第 7 个标签页」。

🐛 修复

图层修复开关此前未真正接到转换管线，勾选无效；现已生效。

图层修复规则：半透明邻居亮度用错像素、部分规则被 if-else 吞掉、饱和度与亮度规则互相覆盖。
