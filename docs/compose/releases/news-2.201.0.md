# 2.201.0

> 本次主题：**界面重做**。配色由 263 种收敛到 123 种并全部令牌化，新增深色模式（含通知窗口与安装器），
> 四个主页面与内嵌面板统一到同一套规范，OOBE 重新排版，通知与安装器接入设计系统。

## 主要变化

### 深色模式

- 浅色主题由「暖白纸面 + 墨」构成，深色按其反相取偏黄的近黑（`#1a1815`），面层逐级提亮、同一色相。覆盖首页、OOBE、启动页，以及所有对话框与侧栏。
- 强调色在深色下**保色相、提明度**，用户选的是颜色而不是明度。混合比 42% 是仍能满足 WCAG AA 的最大值。
- 首页右上角新增太阳/月亮开关，三档：浅色 / 深色 / 跟随系统（默认跟随系统）。
- 主题写入配置随包备份与迁移；启动页另存首帧缓存，避免深色用户每次启动先闪一下浅色。
- 切换主题用**墨水揭示**：由若干墨点组成的遮罩把旧画面揭开，四个墨点的位置、终点半径与用时每次随机，切入方向上下交替。

### 通知窗口与安装器

- **通知 Toast** 此前完全未接入设计系统：28 处硬编码颜色、无深色模式 —— 深色用户每次转换完成看到的仍是白底冷蓝卡片。现已全部令牌化，主题经 URL 传给窗口（每条通知重读，不缓存）。
- **安装器**连接令牌体系并跟随系统深色（首帧同步判色，不会闪白），同时修复了一个**从未渲染过的按钮** —— 失败面板在 `step === 4` 分支内判断 `step === 3`，导致「返回重试」自写出来就没显示过。

### 排版修正

- **中英混排此前走两套字体**：字体栈里 `Segoe UI` 排在 `Microsoft YaHei` 之前，而 Windows 上前三个候选都不存在。实测同一行文字由两种字体渲染（Segoe UI 18 字形 + Microsoft YaHei 15 字形），字重与重心都不同。已改为 CJK 优先，中英同源。
- 中文标题上的**负字距**已归零 —— 负字距是拉丁大标题的技巧，中文是满 em 方块字，会把相邻笔画挤到一起。
- 分组标题此前比它的子项还小（12px vs 14px），层级倒挂，已修正。
- 同一排卡片高度不一致（实测 233 vs 252）已对齐。

### OOBE

- 语言选择由两张国旗卡片改为**一个地球图标 + 一个下拉框**：国旗表示的是国家不是语言，且两面旗比例不同却共用同一槽位。
- 步骤切换并入墨水揭示；内容整体居中。
- 文案修正：中英不对等、同屏重复问候、半角标点、指向不存在的设置键等。

### 其他

- 设置页「动画」一栏新增**实时预览条** —— 用真实的动效变量播放，改档位立刻能看到区别；总开关关闭时预览不播，与真实行为一致。
- 移除一个**永远不会触发的死属性** `animationStyle`（没有任何组件 emit 过它的事件）。

## 转换路径

**本版不改变转换产物。** `arom/`、`natives/`、`native_run.rs`、`pack/` 的差异全部落在文档注释里，`src-tauri/src/` 下新增的可执行代码只有主题配置字段与文件浏览命令两项。如需复核，用 2.200.0 段的冻结内容基线（4018 条目 / 聚合指纹 `0x75bb3260e7f578a6`）即可。

## 已知边界

「支持任意两个版本之间相互转换」有四处例外：GUI 图集切分、马匹界面、叠加图标、副手槽**只做正向，降级时不还原**（反向任务是显式空操作，因为无法从产物反推原状）。跨 1.20.2 边界降级的包，这几处会保留新版形态。
