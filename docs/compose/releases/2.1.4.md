✨ 2.1.4 正式版更新（BUILD 20040）

这是 2-Pyramid 的正式版（tag: Stable-2.1.4）。在 2.1.3 基础上优化分享码与产品用语。

可通过应用内「更新通道 → 稳定版 / 全部」检查到，或直接在 Releases 下载 2-Pyramid-Installer-2.1.4.exe。

✨ 新增

覆盖包分享码升级：前缀改为 2PYR-；导出前会去掉空配置项并压缩，码更短、更易粘贴。旧版 HRCN- 分享码仍可导入。

🔧 改进

产品标语统一为：中文「现代化通用多版本资源包转换器」，英文 Modern Universal Multi-Version Resource Pack Converter。

中英文界面用语润色：统一「资源包」、弱化基岩测试警告、精简导入清单与进度提示等。

发版说明：本 Release 需同时上传 2-Pyramid-Installer-2.1.4.exe 与
2-Pyramid-Installer-2.1.4.exe.sha256 两个资产（更新器 SHA-256 校验依赖后者）。
