✨ 2.1.2 正式版更新（BUILD 20038）

这是 2-Pyramid 的正式版（tag: Stable-2.1.2）。在 2.1.1 基础上优化覆盖包制作体验、补全新木种转换，并加入 N 卡双色循环描边。

可通过应用内「更新通道 → 稳定版 / 全部」检查到，或直接在 Releases 下载 2-Pyramid-Installer-2.1.2.exe。

✨ 新增

覆盖包「双色循环描边」（仅 NVIDIA 显卡）：两种颜色随时间循环过渡；可在视觉设置里用 HSV 取色器调色，并实时预览效果。

1.8 → 1.21.10 新木种转换补全：樱花 / 竹 / 红树木 / 苍白橡木 / 下界菌柄等的木板、原木、竹块映射；旧资源包升到新版本时会生成缺失贴图（26.3 未发布木种暂不加入）。

覆盖包打包时弹出保存对话框，可自定义 zip 输出位置。

🔧 改进

覆盖包页与转换页布局统一（双栏卡片、快速开始、项目配置）。

自定义内容（名称 / 大小 / 视觉）改为右侧滑入侧栏，与版本选择一致；关闭时有滑出动画。

实体描边更准确：彩虹描边区分 N 卡 / 其他显卡；只有「自定义颜色描边」可改颜色（N 卡彩虹本就不可改色）。

樱花调色更接近原版浅粉（此前偏深、偏品红）。

🐛 修复

覆盖包页部分文案未走 i18n。

列表悬停上浮导致描边被裁切。

侧栏关闭缺少滑出动画。
