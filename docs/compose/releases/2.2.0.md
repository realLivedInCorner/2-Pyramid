✨ 2.2.0 正式版更新（BUILD 20042）

这是 2-Pyramid 的正式版（tag: Stable-2.2.0）。本版本补齐法律与合规文档，并在安装器中加入使用须知阅读步骤。

可通过应用内「更新通道 → 稳定版 / 全部」检查到，或直接在 Releases 下载 2-Pyramid-Installer-2.2.0.exe。

✨ 新增

法律与合规文档：仓库 legal/ 下新增 EULA、隐私说明、免责声明、第三方组件声明、安全策略与贡献指南；README 已做索引。

安装器使用须知：安装前可滚动阅读须知与免责摘要；勾选「已阅读并知悉」后继续。这是阅读确认，不附加 MIT 之外的许可限制。

法律文件随包安装：安装后位于安装目录 legal/；可在「设置 → 版本信息 → 法律信息」一键打开。

🔧 改进

package.json 许可证字段修正为 MIT；npm test 在 Windows 下更稳；取消跟踪 Tauri 生成的 schemas 等仓库清理。

🐛 修复

安装器安装失败后的「返回重试」现在回到正确的步骤。
