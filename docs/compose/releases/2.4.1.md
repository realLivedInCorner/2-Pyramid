✨ 2.4.1 正式版更新（BUILD 20046）

这是 2-Pyramid 的正式版（tag: Stable-2.4.1）。修复着色器适配导致的资源包重载失败，并补齐 1.21 旋风系近似贴图生成。

可通过应用内「更新通道 → 稳定版 / 全部」检查到，或直接在 Releases 下载 2-Pyramid-Installer-2.4.1.exe。

✨ 新增

1.21 旋风系贴图生成（Tricky Trials）：升到 1.21（format 34+）时，从包内已有材质近似生成旋风棒、风弹（物品/投掷物）、试炼钥匙与不祥钥匙、旋风刷怪蛋、风充能效果图标、铜灯泡族（含氧化与蜡变体），以及重核、旋风实体、flow 纹饰模板、不祥之瓶。包里已有同名文件时不会覆盖；降版 reverse 会删掉这些生成物。mace、trial spawner、vault、crafter 与粒子等轮廓独特的原版资源不会程序生成。

🐛 修复

着色器适配（按 Minecraft Wiki）：转换后「材质/资源包重载失败」——目标版本已删除的核心着色器仍被留在包里。现在会按版本清理/改名：1.21.6 起 rendertype_* 大量并入 terrain / entity / text 等；26.1、26.3 进一步收敛并删除已移除程序；26.3 将 #moj_import 转为 #include。同时只保留目标版本合法的 post 路径，去掉过期 uniforms，include 文件补末尾空行。
