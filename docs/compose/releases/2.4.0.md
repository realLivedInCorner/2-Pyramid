✨ 2.4.0 正式版更新（BUILD 20045）

这是 2-Pyramid 的正式版（tag: Stable-2.4.0）。跟进 Minecraft Java 版 **26.3 Wilderness Bound**，并完善更新与 OOBE 设置。

可通过应用内「更新通道 → 稳定版 / 全部」检查到，或直接在 Releases 下载 2-Pyramid-Installer-2.4.0.exe。

✨ 新增

Java 26.3（pack_format 97）：版本选择器可作为转换目标；26.2 ↔ 26.3 走着色器适配边。基岩中间态同步升到 26.3。

选择 26.3 时弹出已知问题确认：官方 MC-311807——材质包选择页「打开材质包目录」无反应，后续可能未响应。需确认后才继续选择该目标。

FolderOpenPatch（Fabric 补丁 mod）：配套修复上述缺陷——在 Windows 上改走 explorer.exe 异步打开，不再卡在 SDL_OpenURL / ShellExecute；覆盖材质包 / 光影包 / 截图等本地路径打开。需 Minecraft ~26.3、Fabric Loader ≥0.19.5 与 Fabric API；jar 见独立仓库 FolderOpenPatch，放入 mods/ 后重启即可。

自动检查更新开关：设置 → 版本可关闭「启动时自动检查更新」；OOBE 第 4 步可一并选择更新通道与该开关。

Poplar（杨树）木种：从 1.8 已有木种生成原木 / 木板 / 去皮、门 / 活板门 / 告示牌 / 悬挂告示牌 / 船 / shelf / 树苗，以及三色树叶近似（钉色相，非相对偏移）。垫子、层架蘑菇、红灌木不自动生成。

🐛 修复

26.3 pack.mcmeta 兼容：min_format / max_format 写 [97,0]–[97,1]，去掉会令游戏判不兼容的 pack_format:34 与跨大版本 supported_formats。

Poplar 树叶颜色：不再对近灰的橡木叶做相对色相偏移（会漂成蓝紫），改为钉在红 8° / 橙 28° / 黄 45°。

debug 编译：ClientToScreen / RGBQUAD 的 windows-sys 路径修正（仅影响 dev / cargo check）。
