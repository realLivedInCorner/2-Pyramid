# 2.203.0

> 本次主题：**更新器重做**。更新不再是一个弹窗，而是一个独立页面；失败可以重试、可以看清原因；
> 校验文件取不到时可以显式选择跳过。另修复一个会把自定义按钮样式改坏的转换问题。

## 主要变化

### 更新页面

更新器此前是一个盖在当前界面上的弹窗。八个状态 —— 检查中 / 有新版本 / 已是最新 / 检查失败 / 下载中 / 校验中 / 校验失败 / 已就绪 —— 塞进弹窗本来就局促，四个状态还需要独占主操作区。

现在它是一个独立页面：页头、可滚动的正文、钉在页脚的主动作。**页脚固定是实测出来的**：1240×800 下第一版把「立即更新」顶到了首屏外。

- **下载**：显示速度与剩余时间；失败后直接重试，不必关掉重来。重试会先清理上次的半成品，并有互斥防止两个下载并发。
- **失败分类**：网络不通、超时、服务器拒绝、磁盘写入失败、校验不通过、资源缺失 —— 各自一句人话，**技术细节保留在可展开区并可一键复制**（排查依据不该被丢弃）。
- **强制更新**（`Safe-` 通道 / major 跳变）在「有新版本」与「安装中」隐藏返回按钮，与旧弹窗语义一致；但**失败态仍给返回**，不把用户锁死在页面上。

### 跳过 SHA-256 校验 —— 有边界的那种

有用户反馈无法更新。查下来卡在「拿不到校验文件」这一类：发布页缺少 `.sha256`，或者校验文件下载不下来。

**「无法校验」不等于「文件有问题」**，所以这一类现在提供了一个出口。但它是安全边界的降级，按降级来设计：

| 失败类型 | 能否跳过 |
|---|---|
| 拿不到 `.sha256`（资产缺失 / 拉取失败 / 解析失败） | **可以** |
| 哈希算出来**对不上** | **不可以** |

哈希不匹配是「文件可能被篡改或传输损坏」的直接证据，绕过它等于把完整性校验作废，正确补救是重新下载。

四道额外约束：

1. **不是默认** —— 入口 → 免责声明 → 二次确认，两步都必须发生；确认按钮写的是「我已阅读上述说明，仍要跳过校验」。
2. **不能和文件名回退叠加** —— 安装包名不符合发布规范时，域名与命名两道边界已经在靠回退匹配，再跳过校验就是两道同时失效，直接拒绝。
3. **不记忆** —— 只对当次下载有效，重试立刻回到强制校验，不写入配置。
4. **留痕** —— 跳过、落盘、被拒各一条日志；**即使不校验也会把实际哈希算完写进日志**，事后可对账。

界面上的免责声明是暖色发丝框配左侧琥珀竖线，**不用红色** —— 红色在本项目里只表示「已经出错了」，而这里还没出错，是用户在主动选一条保护更少的路；把一个选择渲染成事故，只会让人点得更快。代价段与责任段分开，实测最差对比度 4.98（浅）/ 5.50（深），均在正文阈值之上。

下载域名白名单、安装包文件名匹配、更新标记写入 —— **全部原样保留**。

### 转换修复：按钮描边被抹平

旧版资源包转到 1.21.4+ 时，`gui/widgets.png` 里的按钮被切分成九宫格 sprite。此前对每张切出来的图套了一道「统一边厚」的处理，实现是把最外 1 行复制成 `b` 行：

```
原图 rows 0,1,2 = [深色描边, 高光, 本体…]
处理后 rows 0,1 = [深色描边, 深色描边]     ← 高光被覆盖
```

原版按钮的边框是「1px 描边 + 1px 高光」的立体倒角，`b=2` 时高光行被第二行描边盖掉，四边变成两像素纯深色。**按钮失去倒角，看起来像描边加粗、内缘发黑的方块。**

九宫格的边厚应当由 sprite 的 `gui.scaling` 声明，不该去改像素。已改为原样输出，按钮族与锁定按钮族一致（否则同一界面会出现两种边框）。

> **注意**：这项修复**改变转换产物字节**。2.203.0 的产物与 2.202.0 不再逐字节相同，差异集中在 `assets/minecraft/textures/gui/sprites/widget/` 下的按钮图。

### 内容基线不再冻结

此前有一个钉死的产物指纹（4018 条目 / `0x75bb3260e7f578a6`），用于在产物内容变化时报红。它后来挡住的不是回归，而是**有意的改动** —— 修按钮描边、加物品模型定义，每次都要先去改那个常量。

**一个改代码时就要同步改的数字，不是哨兵。** 现在它只报告不判定：用 `AROM_BASELINE_DUMP` 导出逐条目清单，与上一版清单逐行 diff —— 那才回答「这版和上版差在哪」。

## 已知边界

「支持任意两个版本之间相互转换」有四处例外：GUI 图集切分、马匹界面、叠加图标、副手槽**只做正向，降级时不还原**（反向任务是显式空操作，因为无法从产物反推原状）。跨 1.20.2 边界降级的包，这几处会保留新版形态。

更新器的以下路径**未经真机验证**：真实网络下载、真实取消（粒度是一个数据块，≤512KB 延迟）、真实拉起安装器。界面验证使用 IPC stub 与无头浏览器截图，不是真实安装流程。剪贴板回退只在 Chromium 中验证过，Tauri WebView 未验。
