# Microsoft Store 一览文案（中文(中国)）

> 用于 Partner Center → 2-Pyramid → Store 一览。产品名称已选 **2-Pyramid**。

---

## 说明（Description）*

```
2-Pyramid 是一款完全本地运行的 Minecraft 资源包版本转换器（Windows 桌面应用）。

无论是老包升到新版本，还是把新包降回旧版本，拖入压缩包即可一键转换。覆盖 Java 1.6 至 26.3 等多个目标版本区间，并支持 Java ↔ Bedrock（基岩）结构互转（实验性）。

所有处理均在你的电脑上完成：无账号、无云端上传、无遥测，资源包文件不会离开本机。

主要能力：
• 任意两个 Java 版本区间互转（升版 / 降版）
• Java ↔ Bedrock 双向转换（.mcpack / .zip）
• 批量拖入多个资源包，多线程并行
• 动态贴图、UI 图集、着色器、物品与方块贴图自动适配
• 输出命名模板（版本号 / 名称 / 时间）可自定义
• Overlay 母包叠加，不改动原包即可预览效果
• 中文 / English 双语界面，可自定义背景与动画

适合：材质包作者、整合包维护者、服务器资源管理，以及想在不同 Minecraft 版本间复用资源包的玩家。
```

## 此版本的新增功能（What's new in this version）

```
2.5.0
• 新增 Foray 分析工作台（Editor Mode）：开启后可对资源包做结构分析（ROM 树、文件 / 权限 / 加密 / 解析 / 恶意五类探针）、轻量像素编辑，以及可选的 AI 辅助分析（可关闭，默认不上传贴图原图）。
• 改进系统通知与 Toast 弹出稳定性。
• Foray 导出支持字节保留与回滚（原地覆盖前自动备份）。
• 安全增强：ZIP 解压增加路径穿越（Zip Slip）防护。
• 本版本起经 Microsoft Store 分发（MSIX）。
```
