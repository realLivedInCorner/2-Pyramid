## Description *

```
2-Pyramid is a fully local Minecraft resource pack converter for Windows.

Whether you are upgrading an old pack to a newer game version or rolling a new pack back to an older one, drop in the zip and convert in one step. It covers a wide range of Java target versions from 1.6 through 26.3, and supports experimental Java ↔ Bedrock structure conversion.

Everything runs on your PC: no account, no cloud upload, no telemetry. Your resource pack files never leave your machine.

What you can do:
• Convert between Java version ranges (upgrade or downgrade)
• Convert Java ↔ Bedrock (.mcpack / .zip)
• Batch-process multiple packs with multi-threading
• Auto-adapt animated textures, UI atlases, shaders, and item/block textures
• Customize output name templates (version / name / time)
• Overlay packs on a parent pack without modifying the original
• Chinese / English UI with custom background and animations

Built for texture pack authors, modpack maintainers, server asset managers, and players who reuse packs across Minecraft versions.
```
