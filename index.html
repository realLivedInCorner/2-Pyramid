[S1] 问题与定位

做包 / 改包 / 审包缺少一体化工作台；风险后知后觉；改像素成本高；AI 黑盒不可控。

痛点Foray 对策
结构看不清，需外部解包ROM 对象树 + 类型统计大视图
加密 / 脚本 / 恶意 zip 难发现五探针 + 恶意启发式 + 安全预检门禁
只为改几像素也要开 PS涂抹 / 吸管 / HSV，明确不做图层滤镜
AI 外传与黑盒提示词档位可控、贴图只发概括、提示词 JSON 白盒、免责清晰
触发条件：设置开启 Editor Mode → 主页拖入 zip 进入 Foray； EM 关闭时仍走 Hurray 普通转换。普通转换永远不会被 Foray 劫持。

[S2] 架构位置

2-Pyramid
├── Hurray Engine（转换核心，Rust）           — 不改写 104 转换器
├── Foray（分析工作台，独立模块）             — 本次
│   ├── ROM · Probe · 风险分析 · Paint · AI
├── Desktop UI（Tauri + Vue）                 — 新路由 / 面板
├── Android / TUI / Enzyme                    — 2.5.0 不接
└── Ifaso（外部）                             — 仅互链占位
与 Hurray 关系：平行、不依赖。Foray 结果可「发送到转换」， 转换流程仍走文件流。禁止在本特性把转换器改成对象操作。
ROM 范围：仅 Foray 内存树。Master Enzyme 实时编辑的全量 ROM 迁移 列为 Out of Scope，另开特性。

工作流

EM=on · 拖 zip→ 安全预检→ mcmeta / pack.png→ 目录树 → ROM→ 五探针并行→ 大视图→ AI / 编辑（可选）→ 导出 / 发转换

预检失败拒绝进树；单探针失败不阻断树，标「探针错误」。

ROM（Resource-pack Object Model）

从 DOM 类比：HTML→节点树；材质包→对象树。转换逻辑未来可对象化，但 2.5.0 只在 Foray 落地。

Rom {
  meta: PackMeta            // pack.mcmeta
  icon: ImageRef | null     // pack.png
  root: RomDir
  stats: { files, bytes, byKind }
  issues: RomIssue[]        // 结构 / 探针标注
}
RomFile { path, kind, size, sha256, parse, paintable }
  • 编辑在 ROM 标 dirty，导出时写回；未编辑文件字节级保留。
  • AI 只收档位摘要，不自动上传 zip 或像素。

探针系统

探针内容典型 issue
文件探针数量 / 体积 / 类型分布stats
权限探针只读、权限异常warn
加密探针疑似加密 / 高熵块danger
解析探针损坏 JSON / PNG / 空文件warn / error
恶意探针.exe/.bat/.vbs、双扩展、Zip Slip 等danger

轻量编辑

  • 工具：涂抹（笔刷/不透明度）、吸管、HSV、撤销 ≤50 步。
  • 不做：图层、蒙版、滤镜、3D（交给 Photoshop / Blockbench）。
  • 保存：默认另存 *_foray_*.zip；可选原地覆盖（二次确认 + .bak）。

AI 分析 · 数据档位（OpenAI 兼容）

自备 baseURL + API Key + 模型名。提示词 JSON 白盒可改。默认档位 1。

档发送风险
0无无
1目录树 + 类型极低
2+ pack.mcmeta低
3+ 勾选 JSON 副本中
4+ 勾选着色器源码中高
5+ 贴图概括（非像素）中
    ≥3 必须显式勾选文件；确认前始终显示「将发送」列表与免责声明（外部 API 与作者无关）。

    安全边界（必须满足）

    • Zip：拒绝 .. / 绝对路径 / symlink；单文件 64MiB、总计 1GiB、条目 5 万、深度 32。
    • JSON 嵌套 ≤64、单文件 ≤8MiB；PNG 边长 ≤8192。
    • AI Key 仅本地配置；日志禁止打印；请求只发用户 baseURL。
    • 提示词默认 JSON，可覆盖、可还原。
    Foray 扩大攻击面（解析器 / ROM / 探针被绕过 / AI 注入）。2.5.0 安全审查覆盖 Foray。
